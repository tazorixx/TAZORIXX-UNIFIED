# TAZORIXX Industry Content Library

This Markdown file is the editable source for generic industry information used when a business has no verified service list or description in Excel. It does not certify that any particular business performs these services. Edit the topic descriptions here to change generated websites. All topic content is displayed under industry-wide headings such as “Common Services in Architecture”, never “Our Services”. Verified Excel services always take priority.

Format: each industry begins with `##`; use `Aliases:`, `Category:`, `Headline:`, `Introduction:` and the `### Common Services` / `### Planning Guide` / `### Typical Process` headings. Each entry is `- Title | Description`.
